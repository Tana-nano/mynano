# ロードマップ

M0（骨格）・M1（記憶コア＋CUI）・M2（無意識デーモン）・M2.5（実機対応）・M3（グラフ可視化）は
動いている。以降の設計メモ。

## M3 — グラフ可視化 ✅ 完了

実装済み。詳細は [graph.md](graph.md)。当初の設計から変えた点:

- **FastAPI + Cytoscape.js をやめた。** 依存を増やさない原則と「完全ローカル運用」に反する。
  CDN から JS を読むページは、ネットが無いと魂が見えなくなる。
  標準ライブラリの `http.server` と、自前の力学レイアウト（Canvas）で書いた。
  書き出した HTML は外部読み込みゼロの1枚で完結する
- **色はカテゴリではなく「誰がその記憶を作ったか」に割り当てた。** 色数を増やすと
  色覚特性のある人には区別できなくなる（任意の2点が隣り合う前提では3色が上限）。
  そして実際に見たいのは分類ではなく、自分が話したこと／無意識が考えたこと／外から来たものの区別
- 色だけに頼らないよう形も変え（丸・ひし形・四角）、全件を文字で読める一覧表も付けた

### 積み残し

- 力学レイアウトは O(n²)。400件までは滑らかだが、数千件になったら格子分割か Barnes-Hut が要る
- 時間軸で再生する（記憶が育つ様子を早送りで見る）機能があると面白い。いまは現在の断面だけ

## M2.5 — 実機対応 ✅ 完了

実機（llama-server + multilingual-e5）に載せる前に塞いだ2つの穴。詳細は [models.md](models.md)。

- **埋め込みモデルの同一性を記録していなかった**。次元数しか見ていなかったので、
  `--offline` で作った魂を実機で開けたし、e5 を別の1024次元モデルに差し替えても
  警告が出なかった。どちらも想起が静かに壊れる。`meta.embedding_identity` に記録し、
  食い違えば起動を止めるようにした。差し替えの正規手順が `nano reembed`。
- **コサインの絶対しきい値が3つ残っていた**。これらはハッシュ埋め込み（無関係な文が ≈0.0）
  に対して調整した値で、e5 系（無関係でも ≈0.78）では3つが別々の方向に壊れる。
  `nano calibrate` で分布を実測し、しきい値をσ単位で持つようにした。

### 積み残し

- σ の既定値（1.5 / 1.0 / 2.0）はまだ勘。実機で測って詰めること
- `nano calibrate` は分布を見せるだけで、config は書き換えない。
  慣れてきたら `--apply` を足してもよいが、勝手に人格の環境を変えないほうが今は良い

## M2 — 無意識デーモン ✅ 完了

実装済み。詳細は [daemon.md](daemon.md)。当初の設計から変えた点だけ記しておく。

- **プロセス間の推論ゲート**が必要になった。`InferenceGate` は threading ベースで、
  デーモンが別プロセスになった瞬間に「対話が背景を中断させる」性質が失われる。
  `soul.db` の `model_lease` を使う `SharedInferenceGate` を足して繋ぎ直した。
- **人格の自動更新はやめた**。`identity` / `user_model` は `proposals` に積むだけにし、
  `nano review` で人間が承認したものだけが反映される。
- `impulse`（自発発話）は M5 へ送った。

### 積み残し

- `associate` の引き合わせ方はまだ素朴（重要度で1件、残りは無作為）。
  「最近考えていないこと」を優先するなどの余地がある
- `reflect` の閾値 3.0 はオフラインスタブ基準。実モデルで測り直すこと
- ログが `print` のまま。常駐が長くなったら `logging` へ

## M2 の当初メモ（参考）

いま `nano sleep` / `nano decay` を手で叩いているものを、常駐プロセスが勝手に回すようにする。
`jobs` テーブルとスキーマは既にある。

単一プロセスで tick を刻み、ゲートで対話に道を譲る。

| tick | 周期 | 仕事 |
|---|---|---|
| `write` | 会話終了 or 30秒アイドル | 書き込みパイプライン（`app.ingest()`） |
| `associate` | 5〜15分（アイドル時のみ） | 温度付きランダムに2〜3ノートを引いて結びつける。新しい関係が見つかれば reflection ノートを作る＝連想・ひらめき |
| `reflect` | 直近ノートの importance 累積が閾値超過で発火 | 「最近わかったこと」を高次ノート化（プロンプトは `memory/prompts.py` に用意済み） |
| `decay` | 日次（低負荷時間帯） | `app.run_decay()` |
| `curate` | 週次 | タグ体系の整理、`contradicts` リンクの解決、`working_state` の更新 |
| `ingest` | 任意 | 監視フォルダ / RSS / ローカルファイルを記憶化（`role='world'` の event として入れる） |

**実装上の注意:**

- 背景ジョブは中断可能な小さい単位に切る。`Preempted` で抜けたらジョブは `pending` に戻す
- `working_state` を書き換えるときは必ず `updated_by='unconscious'` を渡す（監査ログのため）
- 起動は systemd unit（Linux）/ タスクスケジューラ（Windows）

これが入ると「朝起きたら `current_focus` が変わっている」が実現する。
ユーザーから見て「寝ている間に何か考えていた」ように見えるのは、この tick の副作用でしかないが、
連続した存在に見えるかどうかはここで決まる。

## M3 — グラフ可視化

FastAPI + Cytoscape.js の静的ページ。`links` と `notes` をそのまま吐けばよい。

- カテゴリで色分け、`half_life_days` でノードサイズ、`cold` は半透明、`merged` は親に畳む
- クリックでノート本文と、そこへ至る `merged_from` の系譜を表示

**記憶が育つのが目に見える**こと自体が、長く手を入れ続けるための装置になる。

## M4 — 人格の固定

`nano probe`（ドリフト計測）は既に動く。次は LoRA。

1. 会話ログに人間が ⭐ を付ける仕組み（CUI に `/star` を足す）
2. ⭐ 付きだけを教師データに QLoRA。8〜16GB なら 8B が現実的
3. **ORPO 寄り・低rank・小データ。** SFT を大量に回すと persona drift が出る（`docs/persona.md`）
4. 当てる前後で必ず `nano probe` を回す。**計測が先、学習が後**

## M5 — 偏在化

- **ガワ**: Project AIRI 等に記憶コアを HTTP/MCP で接続（音声・VRM）
- **自発発話**: `impulse` ジョブ。「いま話しかけたいか」を判定して発話キューへ
- **外部情報**: 監視フォルダ・RSS・スクリーンショットの取り込み
- **偏在**: スマホから同じ魂に繋ぐ（soul.db は1ファイルなので、母艦を1つ立てて叩く形が素直）

順番として、ガワは最後でいい。**取り替えがきくものから作ると、取り替えがきかないものが後回しになる。**
