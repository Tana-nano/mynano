# 記憶グラフを見る

```bash
python -m nano graph                          # ブラウザで開く（localhost:8765）
python -m nano graph --export soul/graph.html # 単体のHTMLに書き出す
```

数字とログだけでは、記憶が「育っている」のか「散らかっている」のか分からない。
**記憶が育つのが目に見えること自体が、長く手を入れ続けるための装置になる。**

## 何が描かれているか

| 見た目 | 意味 |
|---|---|
| **色と形** | その記憶を**誰が作ったか** |
| ● 青い丸 | あなたが話したこと |
| ◆ 橙のひし形 | **無意識が考えたこと**（連想・気づき・統合） |
| ■ 緑の四角 | 外界から入ってきたこと（`soul/inbox/` 経由） |
| **大きさ** | 記憶の強さ（半減期）。想起されるたびに育つ |
| **濃さ** | いま思い出しやすいか（想起可能性）。薄れた記憶は薄い |
| **破線の輪郭** | cold。通常の想起から外れ、明示検索でだけ出る |
| **黒い輪郭** | pinned。決して忘れない記憶 |
| **線** | リンク。太さは関係の強さ。破線は `contradicts`（矛盾） |

橙のひし形が増えていくのが、**寝ている間に nano が考えていた分**です。
最初は1つも無いところから、デーモンを回しているうちに少しずつ現れます。

## 色は3つしか使っていない

分類やタグで塗り分けたくなるが、やっていない。色数を増やすと色覚特性のある人には
区別できなくなるため（隣り合う任意の2点を見分ける前提だと、検証を通るのは3色まで）。
そして実際に見たいのは「これは自分が話したこと / これは nano が考えたこと」の区別であって、
分類ではない。

色だけに意味を持たせないよう、**形も変えてある**（丸・ひし形・四角）。
凡例は常に出ていて、`一覧` に切り替えれば全部を文字で読める。

## 操作

| したいこと | やり方 |
|---|---|
| 記憶の詳細を見る | ノードをクリック |
| 探す | 右上の検索欄（本文・文脈・タグ・キーワード） |
| 動かす | ノードをドラッグ |
| 見回す | 背景をドラッグ / ホイールで拡大縮小 |
| 全体を表示 | `⤢` ボタン、または背景をダブルクリック |
| 一覧で読む | `一覧` ボタン（重要度×想起可能性の順） |
| 明るさ | `◐` ボタン |

詳細パネルには、重要度・半減期・想起された回数・その記憶が生まれた会話の要約、
そして**統合された記憶の系譜**（この記憶に何が吸収されたか）が出る。

## 書き出し

```bash
python -m nano graph --export soul/graph.html
```

**このファイル1枚で完結している。** 外部の JS も CSS もフォントも読み込まない。
CDN を使えばグラフ描画は数行で済むが、ネットが無いと魂が見えなくなる。
「完全ローカル運用」と「10年後も動く」を掲げている以上、そこは自前で書いてある。

そのまま別のマシンに持っていっても、10年後に開いても、同じように表示される。

## 大きくなってきたら

既定では 400 件まで描く。それを超えると、いま効いている記憶（重要度 × 想起可能性）から
順に切り出す。全部描いても読めないので。

```bash
python -m nano graph --limit 1000
```

「つながり」が異様に多い（記憶の数に対して線が多すぎる）ときは、
リンクのしきい値が緩すぎる。`nano calibrate` を回して
`pipeline.link_min_sigma` を見直すこと（[models.md](models.md)）。
