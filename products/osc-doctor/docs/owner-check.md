# OSCドクター 出品前の確認（デスクトップ版 VRChat で 15 分）

VR 機器なしで確かめられる項目だけを並べています。結果（画面の文字か `ドキュメント\OscDoctor` の txt）を
そのまま送ってもらえれば、こちらで判定します。README の「既知の制限」のうち、ここで消せるものがあります。

## 準備

- Actions の artifact `osc-doctor-0.1.0-win64` を展開しておく
- Windows の「ドキュメント」に `OscDoctor` フォルダがあれば、中身を消しておく

## 確認 1：VRChat を起動していないとき（1 分）

1. VRChat を終了した状態で `osc-doctor.exe` をダブルクリック
2. 期待：`[NG] VRChat 起動していません` が出て、Enter キーで閉じる
3. 確認：ウィンドウが一瞬で消えずに結果が読めるか、文字化けしていないか

## 確認 2：デスクトップ版 VRChat で普通に使う（5 分）

1. VRChat をデスクトップモードで起動し、ホームワールドに入る
2. アクションメニュー → Options → OSC → Enabled を確認
3. `osc-doctor.exe` をダブルクリック。計測中はキーボードで少し歩く・ジャンプする
4. 期待：
   - `[OK] VRChat` / `[OK] ポート 9000 … VRChat.exe` （**アプリ名が出るか**が未検証項目）
   - `[OK] OSCQuery VRChat を見つけました（VRChat-Client-…）`（**見つかるか**が未検証項目）
   - `[OK] 受信 … 件届きました`（**OSCQuery 経由で届くか**が未検証項目）
   - トラッキングは「デスクトップモードのため対象外です」か「（デスクトップなら対象外です）」の情報行
5. Windows ファイアウォールの確認が出たら、出た文言を控えてから「プライベート ネットワーク」で許可

## 確認 3：わざと失敗させる（5 分）

1. ゲーム内で OSC を **OFF → ON** にしてから `osc-doctor.exe`
   - 期待：「何も届きませんでした（OSCQuery は見つかった）」系の結果。**今の VRChat でも起きるか**が未検証項目
   - 起きなかった場合も、それ自体が有用な情報なので結果を送ってください
2. VRChat を再起動して、もう一度実行 → 確認 2 と同じ結果に戻るか

## 確認 4：キャッシュの退避（3 分）

1. VRChat を終了し、exe のあるフォルダでアドレス欄に `cmd` と入力して Enter（その場所でコマンドプロンプトが開く）
2. `osc-doctor --fix-cache` を実行し、確認に答える
3. 期待：「退避しました: …」と表示され、`ドキュメント\OscDoctor\backup\OSC-日付-時刻` ができる
4. VRChat を起動してアバターを着ると、キャッシュが作り直される（確認 2 をもう一度実行して受信 OK になるか）
