# 【無料】OSCドクター for VRChat ― OSC が動かない原因を診断

## キャッチ

ダブルクリックで 15 秒。OSC が動かない原因と、次にすることを日本語で。

## できること

- VRChat が実際に送っている OSC を受け取って確認（VRChat 内の OSC Debug では見えない「送る側」）
- ポートを使っているアプリの名前を表示（「9001 番は ○○ が使っています」）
- VRChat の OSCQuery、トラッキング送信の同意設定、起動引数、インストーラの残留を順にチェック
- 問い合わせに貼れる診断レポート（ユーザー ID などは伏せ字）
- アバター設定キャッシュを「消さずに退避」して定番の対処を安全に

表情トラッキング、心拍、OyasumiVR、チャットボックス系など、OSC を使うツール全般の「動かない」の切り分けに使えます。
ツールの作者さまへ：お問い合わせ対応で「まずこれのレポートを貼ってください」と案内していただいて大丈夫です。

## 対応環境

- **PC VR / デスクトップ用**（デスクトップではトラッキングの診断のみ対象外）
- **Meta Quest 単機（PC なし）では使えません**
- Windows 10 / 11（64bit）、管理者権限は不要

## 前提ソフト

- VRChat（PC 版）

## 導入手順

1. zip を展開してフォルダを好きな場所に置く
2. VRChat を起動してアバターを着る
3. `osc-doctor.exe` をダブルクリック
4. 計測中は少し体を動かす・しゃべる → 結果の「→」の行が次にすること

## 既知の制限

- 実機の VRChat との組み合わせで十分に確認できていない項目があります（README の「既知の制限」に一覧があります）。おかしな結果が出たら、レポートを添えてお知らせください
- ファイアウォールの設定そのものは調べません
- インターネットへの送信は一切しません
