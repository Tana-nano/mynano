# OSCドクター for VRChat

VRChat の OSC（外部アプリとアバターをつなぐ仕組み）が「動かない」ときに、ダブルクリックで原因を調べて、次にすることを日本語で教えてくれる無料ツールです。

## できること

- **VRChat が実際に送っている OSC を受け取って確認**します（VRChat 内の OSC Debug では見えない「送る側」）
- **ポートを使っているアプリの名前**を表示します（例：「9001 番は VRCFaceTracking.exe が使っています」）
- **VRChat の OSCQuery**（アプリ同士が自動で見つけ合う仕組み）が動いているかを確認します
- 頭・手首のトラッキング送信の**同意設定**が必要かどうかを案内します
- 困ったときに貼れる**診断レポート**（txt）を保存します。あなたのユーザー ID などは伏せ字になります
- アバター設定のキャッシュを**消さずに退避**して、定番の対処を安全に試せます（任意）

## 対応環境

| 環境 | 対応 |
|---|---|
| PC VR（SteamVR / Quest Link / Air Link / Virtual Desktop 等） | ○ すべての診断 |
| デスクトップモード | ○（トラッキングの診断だけ対象外） |
| Meta Quest 単機（PC なし） | × 非対応 |

- Windows 10 / 11（64bit）。管理者権限は不要です。
- VRChat（PC 版）

## 導入手順

1. zip を展開し、中のフォルダ（`osc-doctor-0.1.0-win64`）を好きな場所に置きます。
2. VRChat を起動し、アバターを着た状態にします。
3. `osc-doctor.exe` をダブルクリックします。
4. 計測中（約 15 秒）は、体を少し動かす・手の形を変える・しゃべるなどしてください。
5. 結果が表示されます。`→` の行が「次にすること」です。

初回起動時に Windows から「WindowsによってPCが保護されました」と表示される場合があります。
「詳細情報」→「実行」で起動できます（個人が配布するソフトでよく出る表示です）。
Windows ファイアウォールの確認が出た場合は「プライベート ネットワーク」で許可してください。

## 結果の見かた

```
[OK]   VRChat         起動しています（起動引数 --osc なし）
[OK]   ポート 9000    VRChat.exe が受信に使っています
[情報] ポート 9001    VRCFaceTracking.exe が使っています（OSCドクターは OSCQuery で受信します）
[OK]   OSCQuery       VRChat を見つけました（VRChat-Client-07091F、受信ポート 9000）
[OK]   受信           VRChat から 23 種類・412 件届きました（OSCQuery 経由）
[注意] トラッキング   頭・手首の位置が届いていません
         → VRChat の設定で「Allow Sending Head and Wrist VR Tracking OSC Data」を ON にしてください
```

| 表示 | 意味 |
|---|---|
| `OK` | 問題ありません |
| `情報` | 問題ではありませんが、知っておくと役立つこと |
| `注意` | 一部のアプリや機能が動かない原因になります |
| `NG` | OSC が動かない原因です。まずここから直してください |

レポートは `ドキュメント\OscDoctor\report-日付-時刻.txt` に保存されます。
ツールの作者に問い合わせるときは、このファイルの中身を貼ると話が早く進みます。

### よくある結果と対処

| 結果 | 対処 |
|---|---|
| VRChat が受信していません（OSC が OFF の可能性） | アクションメニュー → Options → OSC → **Enabled** |
| ポート 9000 を ○○ が使っていて、VRChat が受信できません | ○○ を閉じてから VRChat を再起動 |
| VRChat から何も届きませんでした（OSCQuery は見つかった） | ゲーム内で OSC を OFF→ON すると起きることがある不具合です。**VRChat を再起動** |
| 頭・手首の位置が届いていません | VRChat の設定で「Allow Sending Head and Wrist VR Tracking OSC Data」を ON |
| install.exe が残っています | タスクマネージャーで終了するか、PC を再起動 |
| アバターのパラメータが届いていません | 下の「キャッシュの退避」を試す |

## 使い方（オプション）

`osc-doctor.exe` があるフォルダを開き、エクスプローラーのアドレスバーに `cmd` と入力して Enter を押すと、オプション付きで実行できます。

| コマンド | できること |
|---|---|
| `osc-doctor --verbose` | 受け取ったアドレスの一覧も画面に表示します |
| `osc-doctor --send-test` | VRChat のチャットボックスに「OSCドクター: 送信テスト」を 1 回送ります（頭の上に出れば VRChat への送信は正常） |
| `osc-doctor --fix-cache` | アバター設定のキャッシュを退避します（下記） |
| `osc-doctor --seconds 30` | 計測時間を変えます（1〜120 秒、標準 10 秒） |
| `osc-doctor --in-port 9000 --out-port 9001` | VRChat のポートを指定します（起動引数 `--osc` を使っている場合は自動で読み取ります） |
| `osc-doctor --out フォルダ` / `--no-report` | レポートの保存先を変える／保存しない |

### キャッシュの退避（`--fix-cache`）

VRChat はアバターごとの OSC 設定を `%LOCALAPPDATA%Low\VRChat\VRChat\OSC` に保存しています。
これが古いままだと、アバターのパラメータが OSC で動かないことがあります。

`--fix-cache` は、このフォルダを**削除せずに** `ドキュメント\OscDoctor\backup\OSC-日付-時刻` へ移動します（実行前に確認があります）。
移動したあとは、VRChat で OSC を Disable → Enable にするか、アバターを着替え直してください。
元に戻したいときは、退避したフォルダを `OSC` という名前で元の場所に戻します。

## 既知の制限

実機の VRChat がないと確かめられない次の点は、**未検証**です。

- VRChat が OSCQuery で「VRChat-Client-…」という名前で見つかること。見つからない場合も、直接確認に切り替えて調べます。
- VRChat が OSCドクターを OSCQuery で見つけて送ってくること
- Windows で、ポートを使っているアプリの名前が管理者権限なしで取れること（取れないときは「アプリ名は取得できませんでした」と表示します）
- 他のアプリが使っているポートを横取りしない仕組みが Windows で効くこと（使用中のポートはそもそも使わないようにしていますが、念のための二重の対策が未検証です）
- ゲーム内で OSC を OFF→ON した後の不具合が、現在の VRChat でも起きるかどうか

そのほかの制限は次のとおりです。

- Windows ファイアウォールの設定そのものは調べません。
- VRChat はアバターのパラメータを「変化したとき」にしか送りません。計測中にまったく動かないと、正常でも「届きませんでした」になることがあります（その場合は自動で 1 回だけ計測を延長します）。
- デスクトップモードでは、トラッキングの診断は行いません。
- Meta Quest 単機（PC なし）では使えません。

## 取り扱うデータ

- インターネットへの送信は一切行いません（通信は同じ PC 内の VRChat とのやりとりと、ローカルネットワーク内の自動検出のみです）。
- 保存するのはレポート txt だけです。受け取った値そのもの（アバター ID など）は保存しません。
- レポートでは、ユーザー ID（`usr_…`）、アバター ID（`avtr_…`）、ワールド ID（`wrld_…`）、Windows のユーザー名を伏せ字にします。アバターのパラメータ名（例 `GestureLeft`）はそのまま載ります。
- VRChat のログファイルは読みません。

## アンインストール

展開したフォルダと、`ドキュメント\OscDoctor`（レポートと退避したキャッシュ）を削除してください。
