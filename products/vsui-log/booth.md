# V睡ログ ― VR睡眠の記録と来客リスト

## キャッチ

寝る前に起動するだけ。何時に寝て、誰と寝て、誰が来てくれたかが朝わかる。

## できること

- ヘッドセットの動きから、寝落ちと起床の時刻を自動で記録
- 一緒に寝た人・寝ている間に来てくれた人を記録（PC の中だけに保存）
- 今夜のまとめと週次レポート（睡眠時間、平均入眠時刻、連続日数、よく一緒に寝た人）
- X に貼れる共有カード（標準では人数のみ、名前は入りません）
- 来客リストの「お礼済み」チェックと、実績バッジ
- おまけ：寝落ち時のチャットボックス送信、OyasumiVR 同期、アバターギミック連携（仕様を無料公開）

## 対応環境

- **PC VR 用**（SteamVR / Quest Link / Air Link / Virtual Desktop など）
- デスクトップモードは、ワールドと同席者の記録のみ（睡眠時間は計測しません）
- **Meta Quest 単機（PC なし）では使えません**
- Windows 10 / 11（64bit）

## 前提ソフト

- VRChat（PC 版、OSC を有効にしてください）
- 任意：OyasumiVR 1.6 以降（スリープモードと同期する場合）
- Unity での作業は不要です

## 導入手順

1. zip を展開してフォルダを好きな場所に置く
2. VRChat のアクションメニューで OSC を Enabled にする
3. `vsui-log.exe` をダブルクリック
4. そのまま寝る。朝、`vsui-log tonight` で今夜のまとめを見る

## 既知の制限

- 睡眠判定の基準値は調整中です。合わない場合は設定の「感度」を変えてください（判定できなかった夜も滞在の記録は残ります）
- VRChat のアップデートでログ形式が変わると、同席者の記録が止まることがあります（更新で対応します）
- OyasumiVR と同時に使った場合の動作は、発売時点で十分に確認できていません
- ウィンドウは黒い画面（コンソール）です

## OSC が届かないときは

同じ作者の無料ツール「OSCドクター for VRChat」で、原因（ポートの取り合い、VRChat の設定など）を調べられます。
