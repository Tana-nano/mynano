# V睡ログ

寝る前に起動しておくだけで、VR 睡眠（V睡）の「何時に寝て何時に起きたか」「どのワールドで誰と寝たか」「寝ている間に誰が来てくれたか」を記録します。

## できること

- **入眠・起床の自動記録**：ヘッドセットの動きから寝落ちと起床を判定します
- **一緒に寝た人・来てくれた人の記録**：VRChat のログから読み取ります（記録は PC の中だけ）
- **今夜のまとめ／週次レポート**：睡眠時間、平均入眠時刻、連続日数、よく一緒に寝た人
- **共有カード**：X に貼れる画像を作ります（標準では名前は入らず人数のみ）
- **来客リストとお礼チェック**：朝「来てくれてありがとう」を伝え忘れないように
- **実績**：はじめてのV睡、7日連続、ぐっすり、など
- **任意機能**：寝落ち・起床時のチャットボックス送信、OyasumiVR との同期、アバターへのパラメータ送信

## 対応環境

| 環境 | 対応 |
|---|---|
| PC VR（SteamVR / Quest Link / Air Link / Virtual Desktop 等） | ○ すべての機能 |
| デスクトップモード | △ ワールドと同席者の記録のみ（睡眠時間は計測しません） |
| Meta Quest 単機（PC なし） | × 非対応 |

- Windows 10 / 11（64bit）
- VRChat（PC 版）の OSC を有効にしてください
- 任意：OyasumiVR 1.6 以降（スリープモードと同期したい場合）

## 導入手順

1. zip を展開し、中のフォルダ（`vsui-log-0.1.1-win64`）を好きな場所に置きます（デスクトップやドキュメントなど）。
2. VRChat を起動し、アクションメニュー（Expressions）→ **Options → OSC → Enabled** にします。
3. VRChat 内で、トラッキングデータを OSC で送るための **追加の同意画面** が出たら同意します（出ない場合もあります）。
4. `vsui-log.exe` をダブルクリックします。黒いウィンドウに `[VR] 起床中 / … / OSC: OK / ログ: OK` と出ていれば準備完了です。
5. そのまま眠ってください。朝、ウィンドウで Ctrl+C を押すか閉じると記録が確定します（閉じ忘れても、起床後 30 分で自動的に確定します）。

初回起動時に Windows から「WindowsによってPCが保護されました」と表示される場合があります。
「詳細情報」→「実行」で起動できます（個人が配布するソフトでよく出る表示です）。

## 使い方

`vsui-log.exe` をダブルクリックすると記録（常駐）が始まります。
記録を見るときは、`vsui-log.exe` があるフォルダを開き、エクスプローラーのアドレスバーに `cmd` と入力して Enter を押します。開いた画面で次のように入力します。

| コマンド | できること |
|---|---|
| `vsui-log tonight` | 今夜のまとめを表示し、HTML も作ります（`--open` でブラウザで開く） |
| `vsui-log week` | 週次レポート（`--week 2026-W40` で週を指定） |
| `vsui-log card` | 共有カード画像を作ります（名前は入りません） |
| `vsui-log card --names` | 名前入りの共有カード（**公開前に写っている人の同意を得てください**） |
| `vsui-log visitors` | 寝ている間に来た人の一覧 |
| `vsui-log thanks 1` | 一覧の 1 番の人に「お礼済み」を付けます（名前でも指定できます） |
| `vsui-log export` | すべての記録を CSV（Excel で開けます）に書き出します |
| `vsui-log chapters` | 来客時刻のチャプターファイル（録画ツールと突き合わせる用） |
| `vsui-log achievements` | 実績の一覧 |
| `vsui-log forget 名前` / `forget --all` | 指定した人／全員の記録を削除します |
| `vsui-log config` | 設定ファイルを開きます |
| `vsui-log doctor` | うまく動かないときの診断 |

日付を指定するときは `--date 2026-09-29` のように書きます。「夜」の日付は、寝始めた日です（深夜 0 時〜正午に寝た場合は前日の夜として数えます）。

出力されるファイルは `ドキュメント\VsuiLog` に保存されます。

## 設定

`vsui-log config` で開くファイル（`%APPDATA%\VsuiLog\config.toml`）で変更できます。変更後は V睡ログ を再起動してください。

| 項目 | 標準 | 説明 |
|---|---|---|
| `self.display_name` | 自動 | あなたの表示名。自動判定が違うときだけ書きます |
| `osc.mode` | `auto` | `auto`（おすすめ）／`oscquery`／`fixed`（9001 番で受信） |
| `osc.send_parameters` | `true` | アバターに `VsuiLog/Sleeping` などを送る |
| `chatbox.enabled` | `false` | 寝落ち・起床時にチャットボックスへ送る |
| `chatbox.sleep_text` / `wake_text` | おやすみなさい／おはようございます | 送る文 |
| `oyasumi.enabled` | `false` | OyasumiVR のスリープモードと同期する |
| `detect.sensitivity` | `normal` | `high` にすると「寝た」と判定されやすくなります |
| `output.card_show_names` | `false` | `true` で共有カードを標準で名前入りにする |
| `output.directory` | 空 | 出力先を変えたいとき |

`detect.*` の細かい値もありますが、通常は `sensitivity` だけで調整してください。

### OyasumiVR と同期する

OyasumiVR の「OSC Automations」で、スリープモードの ON / OFF 時に
`/avatar/parameters/VsuiLog/OyasumiSleep` へ `true` / `false` を送るよう設定し、
V睡ログ の設定で `oyasumi.enabled = true` にします。

このアドレスは VRChat を経由して届くため、**アバターに `VsuiLog/OyasumiSleep`（Bool）パラメータが必要です**。
OyasumiVR が任意の送信先（Custom target）に対応したバージョンでは、送信先を `127.0.0.1:9010` にすれば、アバターの変更は不要です。

### アバターギミックと連携する

V睡ログ は寝ている間、アバターに次のパラメータを送ります。対応ギミックの作り方は同梱の `GIMMICK_SPEC.md` をご覧ください。

- `VsuiLog/Sleeping`（Bool）：寝ている間 true
- `VsuiLog/Visitors`（Int）：今夜寝ている間に来た人数

## 頭の動きが届かないとき

`OSC: 待機中` のまま変わらない、または「頭の動きが届いていません」と表示される場合：

1. VRChat の OSC が Enabled になっているか確認します。
2. VRChat 内の OSC 設定で、トラッキングデータ送信の同意が必要になっていないか確認します。
3. 他の OSC アプリと同時に使っている場合は `osc.mode = "auto"` のままにします。
4. Windows ファイアウォールの確認が出た場合は「プライベート ネットワーク」で許可します。
5. それでも届かない場合は `osc.mode = "fixed"` にして、他の OSC アプリ（9001 番を使うもの）を閉じて試します。
6. `vsui-log doctor` の結果を添えてお問い合わせください。

OSC がうまく届かない原因をもっと詳しく調べたいときは、同じ作者の無料ツール「OSCドクター for VRChat」（Booth）も使えます。ポートを使っているアプリの名前や、VRChat の設定の抜けを日本語で表示します。

## 既知の制限

- **睡眠判定の基準値は調整中です。** VRChat が送る頭の動きのデータ（頻度・単位）は実機での確認前のため、合わない場合は `detect.sensitivity` を変えてください。判定できなかった夜も「滞在の記録」としては残ります。
- VRChat が V睡ログ を自動で見つける仕組み（OSCQuery）は、環境によって動かない場合があります（その場合は自動で固定ポートに切り替わります）。**未検証**
- OyasumiVR と同時に使った場合の動作は**未検証**です（どちらも OSCQuery 対応のため問題ない想定です）。
- VRChat のログ形式が変わると、同席者の記録が止まることがあります。その場合は更新版をお待ちください（`[log.patterns]` で一時的に対応できます）。
- あなたの表示名の自動判定は、ログの形式によっては数回分のワールド移動が必要です。すぐに記録したい場合は `self.display_name` を設定してください。表示名が決まるまでの夜は、同席者が記録されません。
- ヘッドセットが外れたまま朝まで寝た場合は、外れた時刻で夜が終わります。
- デスクトップモードでは睡眠時間を計測しません。
- Meta Quest 単機（PC なし）では使えません。

## 取り扱うデータ

- 一緒に寝た人・来てくれた人の**表示名とユーザー ID** を、あなたの PC の `%APPDATA%\VsuiLog\vsui.db` にだけ保存します。起きている間に会っただけの人は保存しません。
- インターネットへの送信は一切行いません（通信は同じ PC 内の VRChat とのやりとりのみです）。
- 削除は `vsui-log forget 名前` / `vsui-log forget --all`、またはフォルダ `%APPDATA%\VsuiLog` ごと削除してください。
- **来客や同席者の名前を、本人の同意なく公開しないでください。**

## アンインストール

展開したフォルダと、`%APPDATA%\VsuiLog`（設定と記録）、`ドキュメント\VsuiLog`（出力ファイル）を削除してください。
