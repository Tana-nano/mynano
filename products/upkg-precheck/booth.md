# 【期間限定無料】出品前チェッカー ― unitypackage を Unity なしで検品（Windows 専用）

## キャッチ

zip を重ねてドロップするだけ。他者アセットの混入と入れ忘れを、出品前に日本語でチェック。

## できること

- lilToon・Poiyomi・Modular Avatar・NDMF・VRCFury・VRChat SDK の**混入を検出**し、各配布元の同梱ルールを添えて案内
- パッケージの外を参照しているマテリアル・スクリプト・シェーダーを一覧に（Missing (Script)・ピンク表示の予防）
- 対応アバター別の unitypackage を横断で比べ、共通ファイルの版ずれを検出
- zip の点検：説明書・規約の有無、文字化けする日本語ファイル名、実行ファイルや不要なファイルの混入
- 結果は「直すもの（赤）」「確認するもの（黄）」に分けて、見やすいページでブラウザに表示
- 説明書にそのまま貼って直せる「導入に必要なもの・同梱物」の下書きを保存

Unity を開かず、ファイルを展開せずに数秒で調べます。インターネットへの送信は一切しません。

## 対応環境

- **Windows 専用**（Windows 10 / 11、64bit）。**Mac・Linux では使えません**
- PC VR / デスクトップ用の VRChat 向け商品を作る方のためのツールです。**Meta Quest 単機（PC なし）では使えません**
- 管理者権限は不要です

## 前提ソフト

- なし（Unity・VRChat のインストールは不要です）

## 導入手順

1. zip を展開してフォルダを好きな場所に置く
2. 出品する zip（または unitypackage）を `upkg-precheck.exe` に重ねてドロップ
3. 結果のページが開きます。「赤」は出す前に直すもの、「黄」は確認するもの。`→` の行が次にすること
4. レポートと説明書の下書きは「ドキュメント\UpkgPrecheck」に保存されます

初回起動時に「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」で起動できます（個人が配布するソフトでよく出る表示です）。

## 既知の制限

- 「入れ忘れ候補」は Unity を使わずに推定しているため、問題のないもの（Unity の標準機能など）も黄で出ることがあります
- Windows 11 での動作と、Booth の商品 3 個での検品（明らかな誤検知なし）を確認済みです。まだ確認した数が少ないため、おかしな結果が出たら、レポートを添えてお知らせください（無料期間中のご報告を特に歓迎します）
- 他者アセットの判定は、辞書の作成日時点の版までです。README の「既知の制限」に一覧があります

## 同じ作者のツール

- **OSCドクター for VRChat**（無料）：VRChat の OSC が動かない原因を診断（PC VR / デスクトップ用）
- **V睡ログ**：VR 睡眠の記録と来客リスト（PC VR 用）
