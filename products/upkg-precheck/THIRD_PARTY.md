# サードパーティ ライセンス

出品前チェッカー（unitypackage 検品）の配布物（Windows 版）には、以下のソフトウェアが含まれています。
各ソフトウェアの著作権は、それぞれの作者に帰属します。

| ソフトウェア | 用途 | ライセンス |
|---|---|---|
| Python 3.11 | 実行環境 | Python Software Foundation License |
| PyInstaller ブートローダー | 実行ファイル化 | GPL 2.0（ブートローダー例外付き。同梱物の配布を制限しません） |

## 既知アセットの辞書（`known_assets.json`）の出典

辞書には、各配布元の公開リポジトリにある `.meta` ファイルから集めた**ファイルの識別番号（GUID）とパス**だけが入っています。
各配布元のプログラム・シェーダー・画像などは一切含みません。

| 配布元 | リポジトリ | ライセンス |
|---|---|---|
| lilToon | https://github.com/lilxyzw/lilToon | MIT License（Copyright (c) 2020-2024 lilxyzw） |
| Poiyomi Toon Shader | https://github.com/poiyomi/PoiyomiToonShader | MIT License（Copyright (c) 2026 Poiyomi Labs） |
| Modular Avatar | https://github.com/bdunderscore/modular-avatar | MIT License（Copyright (c) 2022 bd_） |
| NDMF | https://github.com/bdunderscore/ndmf | MIT License（Copyright (c) 2023-2024 bd_ (and other contributors)） |
| VRCFury | https://github.com/VRCFury/VRCFury | VRCFury のライセンス（https://github.com/VRCFury/VRCFury/blob/main/LICENSE.md）。辞書には識別番号とパスだけを載せ、VRCFury 本体は含みません |
| VRChat SDK | — | SDK 本体は取得していません。アバター向け SDK の DLL 6 個の識別番号だけを、公開されている情報から載せています |

各名称は、それぞれの権利者のものです。本製品はこれらの配布元とは関係ありません。
