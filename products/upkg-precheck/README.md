# 出品前チェッカー（unitypackage 検品）

Booth に出す zip（または unitypackage）を exe に重ねてドロップするだけで、Unity を開かずに中身を検品し、
「出す前に直すもの」と「確認するもの」を日本語で教えてくれる、出品者向けのツールです。

**Windows 専用です（Windows 10 / 11、64bit）。Mac・Linux・Meta Quest 単機では使えません。**

## できること

- **他者アセットの混入を見つけます。** lilToon・Poiyomi・Modular Avatar・NDMF・VRCFury・VRChat SDK のファイルが、
  書き出し時の「Include dependencies」などで紛れ込んでいないかを、ファイルの識別番号（GUID）で調べます。
  見つかったときは、各配布元が決めている同梱のルールを添えて案内します。
- **入れ忘れの候補を見つけます。** パッケージの外を参照しているマテリアル・スクリプト・シェーダー・テクスチャを一覧にします
  （「Missing (Script)」や「ピンク表示」の原因になるもの）。
- **対応アバター別のパッケージを横断で比べます。** 同じファイルの版がパッケージごとにずれていないかを調べます。
- **zip の中身を点検します。** 説明書・利用規約の有無、Shift_JIS の日本語ファイル名（海外の PC で文字化けする）、
  実行ファイルや不要なファイル（`__MACOSX` など）の混入を調べます。
- **説明書の下書きを作ります。** 「導入に必要なもの（入手先付き）」「同梱物」「同梱していないもの」を、
  そのまま説明書に貼って直せる形（Markdown）で保存します。

ファイルをディスクに展開せず、ネットワークにも接続しません。調べる zip を書き換えることもありません。

## 対応環境

| 環境 | 対応 |
|---|---|
| Windows 10 / 11（64bit） | ○ |
| Mac / Linux | × 非対応 |
| Meta Quest 単機（PC なし） | × 非対応 |

- **Windows 専用**です。Mac 版・Linux 版はありません。
- PC VR / デスクトップ用の VRChat 向け商品を作る方のための、Windows PC 用ツールです（Quest 単機非対応）。
- Unity と VRChat は不要です（起動していなくても、インストールしていなくても使えます）。
- 管理者権限は不要です。

## 導入手順

1. zip を展開し、中のフォルダ（`upkg-precheck-0.1.0-win64`）を好きな場所に置きます。
2. 出品する zip（または unitypackage、それらが入ったフォルダ）を、`upkg-precheck.exe` のアイコンに重ねてドロップします。
3. 黒い画面に結果が表示され、同じ結果を見やすく並べたページ（`report.html`）がブラウザで開きます。`→` の行が「次にすること」です。黒い画面は Enter キーで閉じます。
4. 結果のページ・レポート・説明書の下書きが `ドキュメント\UpkgPrecheck\<zip の名前>-日付-時刻\` に保存されます。

初回起動時に Windows から「WindowsによってPCが保護されました」と表示される場合があります。
「詳細情報」→「実行」で起動できます（個人が配布するソフトでよく出る表示です）。

## 結果の見かた

```
[赤] P04 Outfit_Karin.unitypackage に lilToon のファイルが 212 個入っています
       → 書き出し時に「Include dependencies」で一緒に選ばれた可能性があります。lilToon を外して書き出し直してください。
         - Assets/lilToon/Shader/lts.shader
[黄] P11 Outfit_Karin.unitypackage がパッケージの外のシェーダーを参照しています（1 種類、参照元 3 個）
       → ピンク表示の原因になります。
[緑] P19 購入者に必要なもの: lilToon, Modular Avatar

結果: 赤 1 / 黄 1 / 緑 1
【出品前に直すものがあります。赤の項目を直してください。】
```

| 表示 | 意味 |
|---|---|
| `赤` | 出す前に直してください（他者アセットの同梱、壊れたファイル、実行ファイルなど） |
| `黄` | 確認してください。問題ないこともあります（外部への参照、長すぎるパスなど） |
| `緑` | 情報です（必要な前提ツール、同梱物の集計など） |

画面には例を 3 件まで表示します。すべての例は、結果のページ（`report.html`。「ほか N 件を表示」で開きます）とレポート（`report.txt`）にあります。
結果のページはパソコンの中のファイルで、インターネットには何も送りません。オプションを付けて実行したときは、自動では開きません。

### よく出る結果と対処

| 結果 | 対処 |
|---|---|
| P04 ○○ のファイルが入っています | Unity で書き出すときに、Include dependencies で一緒に選ばれた ○○ のフォルダのチェックを外してください |
| P05 VRCFury / VRChat SDK だけでできています | ライセンス上、同梱できません。削除して、説明書で入手先を案内してください |
| P11 パッケージの外の○○を参照しています | 入れ忘れでないか確認してください。Unity の標準機能や購入者が別に入れるものなら問題ありません |
| P22 配布元のフォルダの下に、辞書に無いファイルがあります | 配布元の新しいファイルなら外してください。自分で作ったもの（ロックしたシェーダーなど）なら自分のフォルダに移すことを検討してください |
| P23 同梱の別パッケージのファイルを参照しています | 説明書にインポートの順番（共通パッケージ → アバター別パッケージ など）を書いてください |
| X01 同じ ID で中身が違うファイルがあります | 対応アバター別パッケージの共通ファイルの版をそろえてください |
| Z05 日本語のファイル名が Shift_JIS で保存されています | 英数字の名前にするか、UTF-8 で圧縮できるツールで zip を作り直してください |
| Z06 読めないファイルがあります | パスワード付きか、Windows のエクスプローラーが大きなファイルに使う圧縮方式です。通常の圧縮で作り直すと調べられます |

## 使い方（オプション）

`upkg-precheck.exe` があるフォルダを開き、エクスプローラーのアドレスバーに `cmd` と入力して Enter を押すと、オプション付きで実行できます。

| コマンド | できること |
|---|---|
| `upkg-precheck 商品.zip --verbose` | 例をすべて画面に表示します |
| `upkg-precheck 商品.zip --out フォルダ` | 保存先を変えます |
| `upkg-precheck 商品.zip --no-report --no-draft` | レポート・下書きを保存しません |
| `upkg-precheck 商品.zip --allow-exe` | 実行ファイルを赤ではなく黄にします（ツール商品の検品用） |
| `upkg-precheck 商品.zip --max-path 150` | パスの長さの上限を変えます（5〜1000、標準 150） |
| `upkg-precheck 商品.zip --max-read-mb 8192` | zip から読む量の上限を変えます（MB、標準 8192） |
| `upkg-precheck --version` | バージョンと辞書の日付を表示します |

終了コードは、赤が無ければ 0、赤があれば 1、ツール自体のエラーは 2 です（バッチ処理に組み込む方向け）。

## 既知の制限

次の点は、まだ確かめられていない**未検証**の項目です（Windows 11 での基本動作と、Booth の商品 3 個での検品は確認済みです）。

- 実際に Booth で販売されている商品の zip での誤検知の率。お気づきの点はお知らせください。
- Unity の版や書き出しツールによる unitypackage の形の違い（確かめた本物の書き出しは lilToon 1.7.0 の 1 個です）。
- 日本語のファイル名を Shift_JIS で保存した zip（Windows 10 の「送る → 圧縮」などで作ったもの）の読み直し。Windows 11 のエクスプローラーで作った zip は UTF-8 で保存されるため、確認済みです。
- 「ドキュメント」フォルダを OneDrive に移している PC での保存先。
- 結果のページを自動でブラウザで開く動作と、黒い画面の色分け（Windows の従来のコンソール）。
- 同じ ID・同じ場所のファイルが複数のパッケージにあるとき、Unity が実際にどう取り込むか（X02・X03）。
- Poiyomi の「ロック」で作られたシェーダーの置き場所（`_PoiyomiShaders` の下と想定し、黄で知らせます）。

そのほかの制限は次のとおりです。

- 「入れ忘れ候補」（黄）が本当に入れ忘れかは確定できません。Unity の標準パッケージや、購入者の環境にあるものを参照している場合も黄になります。
- VRChat SDK は、アバター向け SDK の主な部品（DLL 6 個）とフォルダ名で判別します。ワールド向け SDK の部品は「辞書に無い DLL の部品（緑）」として表示されます。
- 既知アセットの辞書は作成日（`--version` で表示）時点のものです。新しい版で増えたファイルはフォルダ名だけで判定します。
- Unity のアセットがバイナリ形式で保存されていると参照を調べられません（Asset Serialization Mode を Force Text にすると調べられます）。
- FBX・テクスチャの中身や、プレビュー画像は調べません。
- 危険なスクリプトかどうかの判定はしません（自動で動く・通信する処理があることを知らせるだけです）。
- 結果をファイルに保存（`> log.txt` などのリダイレクト）すると、Shift_JIS で表せない文字（ファイル名の特殊な空白など）は `?` になります。正確な名前は report.txt を見てください。

## 取り扱うデータ

- インターネットへの送信は一切行いません。
- 保存するのは `report.html`・`report.txt`・`readme-draft.md` だけです。レポートには調べたファイルの名前を書き、フルパス（Windows のユーザー名を含む）は書きません。
- 調べた zip や unitypackage を書き換えたり、展開したりしません。

## アンインストール
