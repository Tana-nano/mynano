# 【無料】アップロードドクター for VRChat ― アバターが上げられない原因を診断

## キャッチ

Unity を開かずに、フォルダをドロップするだけ。アップロードできない原因の候補を日本語で。

## できること

- Unity が赤いエラーで開けない・VRChat SDK のメニューが出ないときでも使える（ファイルを読むだけで調べます）
- Unity のバージョン、VCC のパッケージの抜け・バージョン違い、パッケージ同士の必要なバージョンを確認
- Unity のログからコンパイルエラーを「アセット」「VRChat SDK」「その他」に分けて集計し、足りないもの（Modular Avatar、Dynamic Bone など）を推測
- 原因の候補を「確からしさ（高・中・低）」付きで、可能性が高い順に表示。根拠のファイル・行と、次にすることも
- 相談に貼れる診断レポート（ユーザー名・プロジェクト名・ID は伏せ字）

プロジェクトのファイルは 1 つも書き換えません。インターネットへの送信もしません。

アバター・衣装の作者さまへ：導入手順に「アップロードできないときはこれのレポートを送ってください」と書いていただいて大丈夫です。

## 対応環境

- **Unity を使う Windows PC 用**（Windows 10 / 11、64bit）。VRChat を起動する必要はありません（PC VR / デスクトップどちらの方でも使えます）
- **Meta Quest 単機（PC なし）では使えません**
- 対象は VRChat SDK3（Avatars）の Unity プロジェクト

## 前提ソフト

- Unity（VRChat 推奨版。2026-09-30 時点では 2022.3.22f1）と VRChat SDK の入ったプロジェクト
- Unity・VRChat SDK は含まれていません

## 導入手順

1. zip を展開してフォルダを好きな場所に置く
2. できれば Unity を閉じておく（開いたままでも診断できます）
3. アバターの Unity プロジェクトのフォルダを `upload-doctor.exe` にドラッグ＆ドロップ
   - 初回に「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」で起動できます
4. 上から順に、`→` の「次にすること」を試す（試す前にバックアップを）

## 既知の制限

- 動作を確かめた環境は Windows 11 の 1 台です（Unity 2022.3.22f1、VRChat SDK 3.10 系のアバタープロジェクト）。Windows 10 では確かめていません
- アップロード失敗のメッセージは、実際のログで確かめられたのは一部だけです（README の「既知の制限」に一覧があります）。おかしな結果が出たら、レポートを添えてお知らせください
- シーンの中身（Avatar Descriptor、ボーン、ポリゴン数、パラメータ容量）は見ません。これは Unity 内の VRChat SDK パネルの役目です
- 表示するのは「原因の候補」です。確からしさ「低」は推測で、外れることがあります

## 同じ作者のツール

- **OSCドクター for VRChat**（無料）：OSC（外部アプリとアバターをつなぐ仕組み）が動かない原因を、ダブルクリックで診断
- **V睡ログ**：VR 睡眠の記録と来客リスト。何時に寝て、誰と寝て、誰が来てくれたかが朝わかります（PC VR 用）
