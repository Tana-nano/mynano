# アップロードドクター 0.1.1 再試験手順（T2・T3）

`docs/cowork-test.md`（初回の手順書）の T2・T3 を、0.1.1 でもう一度行う。
初回（2026-10-01、0.1.0）で見つかった問題が直ったかを確かめるのが目的。
「守ること」は初回の手順書と同じ。特に次の 3 つを守る。

- 既存のプロジェクト（kip_ookami）は **Unity で開かない**。exe にドロップして読むだけにする。
- VRChat にログインしない、アップロードしない。
- ユーザー名は `<USER>` に置き換える。

## 準備

1. 0.1.1 の成果物をダウンロードする（GitHub にログインしたブラウザで）。
   https://github.com/Tana-nano/mynano/actions/runs/36803203472/artifacts/11136845528
2. 2 回展開して、`C:\UDTest\0.1.1\` の下に置く。`upload-doctor.exe` の場所を記録する。
   0.1.0 のフォルダは消さずに残しておく。
3. `upload-doctor.exe` を初めて起動すると、SmartScreen などの警告が出ることがある。
   - 出たら、**閉じる前に**スクリーンショットを撮り、文面と押したボタンを記録する。
   - 起動・ドラッグなどをエージェントが操作できない場合は、オーナーに操作を頼み、その旨を記録する。
4. Unity はすべて閉じておく。

## R1（T2 の再試験）既存プロジェクト kip_ookami

1. kip_ookami のフォルダを 0.1.1 の `upload-doctor.exe` にドロップする。
2. 画面の結果と、`ドキュメント\UploadDoctor\` に新しくできたレポートの中身を、結果のファイルに貼る。

期待（0.1.0 から変わるはずの点）:

- レポートの「Windows:」が `Windows 11 (10.0.26200)` の形になる。
- レポートの「実行日時」が、ドロップした時刻と合う。exe の起動時刻ではない。
- 「[注意] パッケージ同士のバージョンの条件が合っていません」が出る。
  - 根拠は `vrchat.blackstartx.gesture-manager は com.vrchat.avatars >=3.5.2 < 3.9.X が必要ですが、3.10.4 です`。
- 「分類できないエラー」に `UnityWebRequestException` と `VRCApiError` が**出ない**。
- Editor.log は、前回の試験の後は UDテスト のものになっているはず。そのため次のようになる見込み。これ自体が「別のプロジェクトのログ」の判定の確認になる。
  - 「対象プロジェクト: 不一致」になる。
  - 「この Editor.log は別のプロジェクトのものです」が出る。
  - ログ由来の候補は、確からしさが「低」になる。

## R2（T3 の再試験）試験用プロジェクト UDテスト

### R2-a Unity を閉じた状態

1. Unity が閉じていることを確かめる。
2. `C:\UDTest\日本語フォルダ\UDテスト` を 0.1.1 の exe にドロップし、R1 の 2 と同じく記録する。
3. `C:\UDTest\日本語フォルダ\UDテスト\Temp\UnityLockfile` があるかどうかを記録する。

期待:

- 「分類できないエラー」の候補が出ない（0.1.0 では 13 種類出ていた）。
- 「フォルダのパスに日本語などの文字が含まれています」が「[情報]」になる（0.1.0 では「[注意]」）。
- 「対象プロジェクト: 一致」になる。
- 「Unity でこのプロジェクトを開いている最中のようです」が出ない。
- 結果の要約に「注意」と「NG」が 0 件になる。

### R2-b Unity を開いた状態

1. VCC の「Open Project」で UDテスト を開き、読み込みが終わるまで待つ。
2. `Temp\UnityLockfile` があるかどうかを記録する。
3. Unity を開いたまま、UDテスト を exe にドロップして記録する。
4. Unity を File > Exit で終了する。
5. もう一度 `Temp\UnityLockfile` があるかどうかを記録する。

期待:

- 3 の結果に「[情報] Unity でこのプロジェクトを開いている最中のようです」が出る。
- 2 では `UnityLockfile` があり、5 では無い。
  - この見込みはまだ確かめていない。違ったら、そのまま記録する。
