# 更新履歴

## 0.1.1 - 2026-10-01

Windows 11 の実機での試験結果を反映しました。

- Unity がスクリプトを読み込んだ記録（ファイル名に Error や Exception を含むもの）を、エラーと数えていたのを直しました
- パッケージが必要とするバージョンの条件で、`>=3.5.2 < 3.9.X` のような書き方を判定できるようにしました。判定できない書き方は、そう表示します
- エラーの出ていたファイルがもう無いときは、そう添えて確からしさを「低」に下げるようにしました
- Unity でプロジェクトを開いている最中のときに、そう表示するようにしました
- フォルダ名に日本語があるときの表示を「注意」から「情報」にしました（実機で問題なく開けたため）
- レポートの実行日時を、exe を起動した時刻ではなく診断した時刻にしました
- Windows 11 が「Windows 10」と表示されていたのを直しました

## 0.1.0 - 2026-09-30

- 初版（無料）
- Unity プロジェクトのフォルダを読み取り専用で点検（Unity のバージョン、VCC のパッケージ一覧と実体、パッケージ同士の依存、旧 SDK の二重導入、SDK2 の設定の残り、SDK の版、日本語・長いパス、旧 Dynamic Bone のフォルダ）
- Unity の Editor.log を解析（コンパイルエラーを Assets・SDK・その他に分けて重複なしで集計、足りない型・名前空間の一覧、アップロード失敗の記録、分類できないエラー）
- 別のプロジェクトのログ・古いログの見分け
- 原因の候補を「状態」「確からしさ（高・中・低）」の順に表示し、根拠と次にすることを添える
- 診断レポート（ユーザー名・プロジェクト名・ID は伏せ字）
- 判定の規則表（rules.json）を差し替え可能
