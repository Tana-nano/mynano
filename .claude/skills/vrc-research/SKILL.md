# 市場調査 (/vrc-research)

目的: 「作るべきか」「いくらで」「何と差別化するか」を出典付きで判断できる状態にする。

## 手順

1. **調査テーマを1行で決める**（例: "VR睡眠のログ/分析ツール"）。
2. **WebSearch を並列で投げる**。最低でも次の観点を1クエリずつ:
   - Booth 内の競合（`Booth VRChat <テーマ>`）と価格
   - 無料の強豪（GitHub / Steam / note で配布されているもの）
   - 直近3ヶ月のトレンド（vrcfinder.net の月次レポート、メタカル最前線の週刊トレンド）
   - VRChat 公式の直近アップデート（機能追加で需要が消える/生まれる）
   - ユーザー層データ（新規層・デスクトップ率・無言勢など）
   - 他ゲーム/現実の類似ヒット（心理・売り方の参考）
3. **egress でブロックされたドメインは検索結果の要約で代用**し、その旨を書く。
   （既知: vrcfinder.net, metacul-frontier.com, moguravr.com, zenn.dev, note の一部は直接読めない）
4. `docs/market/<topic>.md` に以下の形式で保存する。

## 出力形式 (docs/market/<topic>.md)

```
# <テーマ>  (調査日: YYYY-MM-DD)

## 結論（3行以内）
## 競合一覧
| 名前 | 種別 | 価格 | 強み | 弱み | URL |
## 無料の強豪
## トレンド・公式アップデートの影響
## ユーザー層と需要の根拠
## 差別化の仮説
## 未確認事項
## 出典
```

## ルール

- 価格・販売数・機能は出典 URL とセットで書く。出典が無い数字は書かない。
- 「AI 製とバレる」リスク（3D モデル・画像）に触れる商品は候補から外すか、システム部分だけに切り出す。
- 結論は「やる / やらない / 条件付き」のどれかで締める。
